This repository contains presentations I created as part of my learning journey in AWS Generative AI Development.

The goal of these presentation is to understand AWS services through simple explanations with real-world architecture concepts.

## Topic covered ##
1. Amazon Glue
2. Amazon OpenSearch Service
3. Amazon RDS

## Amazon Glue

The Amazon Glue presentation focus on data integration, ETL, data discovery and preparing data for analytics and AI workloads.

## Includes
1. What is Amazon Glue?
2. Amazon Glue Crawlers
3. AWS Glue Data Catalog
4. AWS ETL Jobs
5. AWS Glue and Amazon S3 Partitions
6. AWS Glue Studio
7. AWS Glue Data Quality
8. Amazon Glue in a Generative AI Pipeline


## Key Concepts

Amazon Glue is a serverless and fully managed service that can discover data, understand its schema, perform ETL operations, and connect with different data sources.


## 2. Amazon OpenSearch Service

The Amazon OpenSearch Service presentation explores search, analytics, vector search, semantic search, and its role in Generative AI and RAG applications.

## Topc Covered

1. Amazon OpenSerach Service
2. OpenSearch as a Vector Store
3. Keyword Search vs. Semantic Search
4. Hybrid Search
5. OpenSearch Serverless
6. Vector Search Engines
7. Exact Nearest Neighbor Search
8. HNSW and IVF
9. OpenSearch Performance and Sharding
10. OpenSearch in a RAG Architecture

## Key Concept

The presentation explains how OpenSearch can store vector embeddings and retrieve relevant document chunks for Generative AI applications.

## 3. Amazon RDS

## Topics Covered

1. Amazon RDS
2. Use if Amazon RDS
3. RDS Storage AUto Scaling
4. RDS and Amazon S3
5. Amazon Aurora
6. Aurora High Availability and Read Scaling
7. Aurora features and Backtrack
